// WorldFactor=0 && LocalFactor=0 : freeze cloth
// WindInMovementDirection means apply wind in direction of movement (scale wind by dp)
// SpecialCollision means to use extra collision for moving backwards that keeps the cape
//    from getting entangled in the character
// LocalDir:
//    -Y = head to foot, -Z = away from back

	LocalDir	0.0 0.25 -0.9375
End
